# История изменений

## 1.0.0 — 2026-11-24

- Динамический блок Gutenberg с PHP-рендером, Interactivity API и поддержкой настройки внешнего вида через `theme.json`.
- Баннер с принятием, отказом и отдельными переключателями для необязательных скриптов. Настройки можно повторно открыть ссылкой `#cookie-preferences`.
- Согласие хранится 180 дней. При изменении списка скриптов плагин запрашивает согласие заново.
- Страница настроек WordPress для редактирования текста и списка необязательных скриптов.
- Русский и английский интерфейсы, адаптивная раскладка и управление с клавиатуры.
